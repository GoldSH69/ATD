# Changelog — 2026.07.04

## Session: Build AutoThreads — Threads post-automation studio with local/cloud LLM (10:32)

Brand-new sibling app to AppTest, same stack (Electron + Vite + React 19 + TypeScript, zero native deps), built in `c:\_sites\autothreads-locallm`.

### Added
- **App foundation** — Electron main/preload, dev/build/start scripts, tsconfig split, monotone light/dark design system mirroring the AppTest scaffold. (`electron/`, `scripts/`, `src/styles/app.css`)
- **LLM provider layer** — adapters + connection tests for Claude API, OpenAI API, and any local OpenAI-compatible server (Ollama/LM Studio). (`electron/llm.ts`)
- **Threads Graph API client** — two-step publish, reply publishing, my-posts fetch, style-sample scrape, and unanswered-reply detection. (`electron/threadsApi.ts`)
- **News scraper** — Google News RSS per topic, regex-parsed, degrades to `[]`. (`electron/news.ts`)
- **Generation pipeline + scheduler** — voice-aware prompt building, draft post/reply generation, background publisher for due scheduled posts, and optional auto-drafting. (`electron/pipeline.ts`, `electron/scheduler.ts`)
- **Five views** — Drafts (master/detail editor), News, Replies, Queue, Settings. (`src/components/`)
- **Onboarding setup wizard** — modal with left step-nav, per-step "Save and continue" / "Previous", live connection tests, and a summary; rerunnable from Settings. Shown on first run via a new `onboarded` setting. (`src/components/Onboarding.tsx`)
- **Secret encryption at rest** — API keys + Threads token encrypted via Electron `safeStorage` (DPAPI/Keychain). (`electron/settings.ts`)
- **Open-source docs** — full GitHub README + MIT license. (`README.md`, `LICENSE`)

### Fixed
- 22 adversarially-confirmed review findings (2 critical, 8 major, 12 minor). Notable:
  - Claude generation sent `temperature: 0.8`, which the default model rejects with HTTP 400 → dropped it, raised `max_tokens`. (`electron/llm.ts`)
  - LLM response body was read after the abort timer cleared → a stalled stream hung generation forever; body now consumed inside the timeout window. (`electron/llm.ts`)
  - Scheduler could publish a draft the user unscheduled mid-tick, and a racing renderer upsert could roll back a `posting` draft → re-check due-status per publish, protect scheduler-owned statuses, sanitize all draft IPC input. (`electron/scheduler.ts`, `electron/drafts.ts`)
  - Empty/over-limit scheduled drafts retried every 30s forever → now fail once and surface. (`electron/scheduler.ts`, `src/components/DraftsView.tsx`)
  - Emptied topics list silently resurrected to defaults on save → persists empty. (`electron/settings.ts`)

### Security
- `will-navigate` allowlist compared string prefixes (`http://localhost:5174@evil.com` bypassed it) → now compares parsed URL origins. (`electron/main.ts`)
- Draft IPC input sanitized/coerced before it can reach the scheduler; local LLM base URL validated as a proper http/https URL. (`electron/drafts.ts`, `electron/llm.ts`)

### Docs
- README documents full functionality, provider setup, Threads token scopes, architecture diagram, and project layout for open-source release.

### Open / next
