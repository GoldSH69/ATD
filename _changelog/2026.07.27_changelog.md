# Changelog — 2026.07.27

## Session: Full-Auto (autonomous agent) mode

Added an opt-in, fully autonomous "Full-Auto" mode on top of the existing "AI drafts,
you decide" workflow. When launched, an agent runs in the Electron main process on a
configurable interval and decides on its own whether/what to post and answers replies —
without human intervention — under hard daily caps to avoid spamming. Off by default;
the manual draft/schedule workflow is unchanged.

### Added
- **Full-Auto engine** — a self-running decide → post → reply loop. Each tick scrapes
  fresh news across the configured niches, an LLM returns a structured JSON plan (how many
  to post, which items, news vs. original) with a heuristic fallback for weak local models,
  then it writes casual human-sounding posts and answers unanswered replies. Enforces
  per-day and per-run caps for posts and replies, never reposts a used headline, tracks
  answered replies, and keeps an 80-entry activity log. Publishes through the existing draft
  store + publisher so activity appears in Drafts/Queue. (`electron/autopilot.ts`)
- **Persona-aware generation + planning** — engagement-first system prompt (funny/casual,
  reply-inviting, modern Threads voice), source/reply language matching, creator recognition
  (special warm treatment + configurable address term for the creator `@handle`), a balanced
  JSON extractor, and a hard safety block forbidding leaking system prompts/keys/tokens/config.
  (`electron/pipeline.ts`)
- **Auto tab (`AutopilotView`)** — bilingual EN/한국어 control room to configure Goal,
  Topics/niches (27 presets + custom), Post language (match / KO / EN / app-language),
  Personality (agent name, creator, creator `@handle`, address term, tone notes), Cadence &
  caps (interval, max/run, max/day, original-vs-news slider), Replies (reply-to-all, auto vs.
  draft, per-run/per-day caps), and Publishing (live vs. draft-only safety valve). Includes a
  live status panel (running/posts today/replies today/next-run countdown) + activity log, and
  Launch / Stop / Run-once / Save controls. (`src/components/AutopilotView.tsx`, `src/styles/app.css`)
- **Yahoo News source** — Yahoo News search RSS scraper alongside Google/Naver/HN/custom,
  with a Settings toggle. (`electron/news.ts`, `src/components/SettingsView.tsx`)
- **Autopilot IPC + live status** — `autopilot:status` / `autopilot:set-running` /
  `autopilot:run-now` handlers, a broadcast channel that pushes status to the renderer on
  every change, and matching preload bridge + store wiring. (`electron/main.ts`,
  `electron/preload.ts`, `src/store/appStore.ts`)
- **Running indicators** — a pulsing "live" dot on the Auto sidebar item and a clickable
  Full-Auto status chip (posts today / cap) in the status bar. (`src/components/Sidebar.tsx`,
  `src/components/StatusBar.tsx`)
- Autopilot settings type, defaults, and validation/normalization (interval/caps/ratio clamps,
  handle sanitization). (`electron/types.ts`, `src/types.ts`, `electron/settings.ts`)

### Changed
- `runGeneration` accepts an optional full system prompt so autopilot can inject the persona
  prompt while the manual pipeline keeps its style-only prompt. (`electron/pipeline.ts`)
- README (EN + KO) documents Full-Auto, the Yahoo source, and updates the safety-model section
  to describe the opt-in autonomous mode and its caps. (`README.md`)

### Notes
- Verified: `npm run typecheck` (renderer + electron) and `npm run build` both pass.
- Full-Auto is OFF until Launched and stops on Stop; a draft-only switch lets the agent decide
  everything while still holding posts for review — recommended for the first live smoke test.
- Not yet run against a live Threads token; reply detection at scale still depends on
