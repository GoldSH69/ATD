# Changelog — 2026.07.27

## Release 0.2.0 — Full-Auto (autonomous agent) mode

Shipped an opt-in, fully autonomous **Full-Auto** mode on top of the existing *"AI drafts, you
decide"* workflow. When launched, an agent runs in the Electron main process on a configurable
interval and decides whether/what to post and answers replies — under hard daily caps to avoid
spamming. Off by default; the manual draft/schedule workflow is unchanged.

Also formalized open-source release hygiene: root `CHANGELOG.md`, version **0.2.0**, polished
README Full-Auto docs (EN + KO), and a proper GitHub release with installers.

### Added
- **Full-Auto engine** — self-running decide → post → reply loop. Each tick scrapes fresh news
  across configured niches; the LLM returns a structured JSON plan (how many to post, which items,
  news vs original) with a heuristic fallback for weak local models; then it writes casual
  human-sounding posts and answers unanswered replies. Enforces per-day and per-run caps, never
  reposts a used headline, tracks answered replies, and keeps an 80-entry activity log. Publishes
  through the existing draft store + publisher so activity appears in Drafts/Queue.
  (`electron/autopilot.ts`)
- **Persona-aware generation + planning** — engagement-first system prompt, source/reply language
  matching, creator recognition (warm treatment + configurable address term for the creator
  `@handle`), balanced JSON extractor, and a hard safety block forbidding leaking system
  prompts/keys/tokens/config. (`electron/pipeline.ts`)
- **Auto tab (`AutopilotView`)** — bilingual EN/한국어 control room: Goal, Topics/niches
  (27 presets + custom), Post language, Personality, Cadence & caps, Replies, Publishing
  (live vs draft-only). Live status panel + activity log; Launch / Stop / Run-once / Save.
  (`src/components/AutopilotView.tsx`, `src/styles/app.css`)
- **Yahoo News source** — Yahoo News search RSS alongside Google/Naver/HN/custom, with a Settings
  toggle. (`electron/news.ts`, `src/components/SettingsView.tsx`)
- **Autopilot IPC + live status** — `autopilot:status` / `autopilot:set-running` /
  `autopilot:run-now`, broadcast channel to the renderer, preload + store wiring.
  (`electron/main.ts`, `electron/preload.ts`, `src/store/appStore.ts`)
- **Running indicators** — pulsing live dot on the Auto sidebar item; Full-Auto status chip in the
  status bar. (`src/components/Sidebar.tsx`, `src/components/StatusBar.tsx`)
- Autopilot settings types, defaults, validation/normalization.
  (`electron/types.ts`, `src/types.ts`, `electron/settings.ts`)
- Root **`CHANGELOG.md`** (Keep a Changelog) for release consumers.

### Changed
- `runGeneration` accepts an optional full system prompt so autopilot can inject the persona prompt
  while the manual pipeline keeps its style-only prompt. (`electron/pipeline.ts`)
- README (EN + KO) expanded Full-Auto docs: loop diagram, config table, controls, first-run
  checklist, safety callouts; version badge **0.2.0**. (`README.md`)
- `scripts/dev.js` waits for Vite on `localhost` / `::1` as well as `127.0.0.1` so Electron launches
  reliably when Vite binds IPv6-only on macOS.
- Package version and description updated to **0.2.0**. (`package.json`)
- `.gitignore` ignores macOS AppleDouble `._*` files.
- **Popular Threads niches (AI-first)** — Full-Auto defaults and news seeds favor high-engagement
  categories (AI, tech, startups, productivity, humor…); per-niche voice coaching so posts sound
  like native AI/tech Threads, not press releases; Auto tab groups Popular vs More with one-click
  popular defaults. (`electron/pipeline.ts`, `electron/autopilot.ts`, `src/components/AutopilotView.tsx`)

### Notes
- Verified: `npm run typecheck` and `npm run build` pass; desktop smoke-test via `npm run dev`.
- Full-Auto is OFF until Launched and stops on Stop; draft-only is recommended for the first live
  smoke test.
- Reply detection at scale still depends on `/conversation` availability per Threads token
  (pre-existing caveat).
